# MGSV 1.0.15.4 修改器兼容补丁

修复风灵月影《合金装备5：幻痛》v1.0–v1.15 二十二项修改器（Build.2020.07.05）在游戏 1.0.15.4 中启用以下功能时出现的“没有找到地址”错误：

- 无限 GMP
- 无限英雄主义点数
- 无限资源

这是非官方兼容修补，与原修改器作者无隶属关系。原修改器由风灵月影制作；本项目提供修补逻辑和使用说明。

## 使用方法

需要 Python 3，无第三方依赖。先关闭修改器，再运行：

```powershell
python patch_trainer.py "Metal Gear Solid V The Phantom Pain v1.0-v1.15 Plus 22 Trainer.exe" "MGSV Trainer Fixed.exe"
```

脚本严格校验输入文件，仅支持下表中的原版。它生成一个新文件，不覆盖原修改器，不改动游戏、存档或其他文件。随后运行生成的修改器，使用 Ctrl+数字键盘 1、2、3 开启对应功能。

如需从修补版还原原版，可指定一个不存在的输出文件：

```powershell
python patch_trainer.py "MGSV Trainer Fixed.exe" "MGSV Trainer Restored.exe" --reverse
```

## 修补原理

新版游戏对部分语义相同的指令使用了不同编码，旧修改器的精确字节搜索因此失效：

- GMP／英雄主义：`31 C9` → `33 C9`，均为 `xor ecx, ecx`。同步修改三处字符串，涵盖搜索、注入及恢复代码。
- 资源：`89 CA` → `8B D1`，均为 `mov edx, ecx`。修改 `41 8B 0C 00` 后的两处字符串，涵盖搜索和恢复代码。

补丁保留原修改器界面、快捷键及数值设置。
